Estas guías son prácticas básicas del lenguaje de progrmación Kotlin
Contiene 2 guías:

La primera guía:
* Se crean variables para realizar operaciones aritméticas básicas
* Se crean variables de tipo String para manejar errores de tipo NPE
* Se crea un Case When para enumerar los días de la semana

La segunda guía:
🎯Objetivos:
- Practicar el uso de ciclos (`for`, `while`, `forEach`).
- Conocer las colecciones básicas (`List`, `Set`, `Map`).
- Aplicar operaciones típicas (`map`, `filter`, `sum`, `average`).
- Escribir funciones simples en Kotlin.
- Aprender a **subir el proyecto a GitHub** y entregar correctamente la evidencia.
